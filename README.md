
# AI Study Assistant 🎓

## Project Description

AI Study Assistant is an AI-powered educational
application developed using Python, Streamlit
and Groq AI.

It helps students understand difficult topics,
summarize notes and practice questions.

## Features

- AI Chatbot
- Study Notes Summarizer
- Topic Explainer
- Quiz Generator
- PDF and TXT file upload
- Download summaries and quizzes

## Technologies Used

- Python
- Streamlit
- Groq AI
- PyPDF
- VS Code

## Installation

1. Clone the repository.

2. Install dependencies:

   py -m pip install -r requirements.txt

3. Create .streamlit/secrets.toml.

4. Add your Groq API key:

   GROQ_API_KEY = "your_api_key"

5. Run the application:

   py -m streamlit run app.py
